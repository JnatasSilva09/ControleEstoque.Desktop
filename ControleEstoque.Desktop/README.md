# Controle de Estoque - Versão Desktop

Sistema de controle de estoque desenvolvido em C# / .NET 8 / Windows Forms / SQLite / Entity Framework Core.

## Como rodar o projeto

1. Instale o [.NET 8 SDK](https://dotnet.microsoft.com/download).
2. Abra a pasta `ControleEstoque.Desktop` no terminal.
3. Execute os comandos:
```
```bash
dotnet restore
dotnet build
dotnet run
```
